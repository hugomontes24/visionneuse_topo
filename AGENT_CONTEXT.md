# Contexte métier


## Site


Un site représente une zone d'étude ou un chantier.


## Raster


Un raster représente généralement une orthophotographie.


Les rasters sont souvent organisés par campagne ou par date.


## Réseaux


Deux types principaux :


- EP : eaux pluviales
- EU : eaux usées


Les réseaux sont composés :


- de canalisations (Pipe)
- de tampons (Tampon)


## Avant / Après


Le mode Avant / Après permet de comparer deux orthophotographies de dates différentes.


## Modèle 3D


Le modèle 3D représente une reconstruction photogrammétrique du site.


## Nuage de points


Le nuage de points permet l'inspection détaillée des relevés.
